# Custom Schematics

Custom block schematics for analog, mixed-signal, memory, IO, and custom logic blocks.

## Supported Formats

- CDL netlists (SPICE-compatible)
- Verilog-A behavioral models
- OpenAccess databases (via tool-specific flows)

## Naming Convention

Each custom block should have:
- `<block_name>.cdl` — CDL netlist for LVS
- `<block_name>.spice` — SPICE netlist for simulation
- `<block_name>.v` — Verilog behavioral model for digital integration
- `<block_name>.lib` — Liberty model (generated by characterization)
